# photoSelector 操作説明書

photoSelectorは、大量の写真を効率的に整理・分類するためのmacOSアプリケーションです。

## 基本的な使い方

### 1. フォルダを開く

1. 左上の「Open Folder」ボタンをクリック
2. 整理したい写真が入っているフォルダを選択
3. 対応している画像形式: JPG, PNG, HEIC, GIF, TIFF、および主要なカメラRAW形式（詳細は[RAWファイル対応](#rawファイル対応)を参照）

### 2. 写真を分類する

写真は3つの状態に分類できます：

- **未分類**（枠なし）
- **採択**（緑の枠）
- **ボツ**（赤の枠）

#### 分類方法

- クリックは「選択」のみを行います（クリックで状態は切り替わりません）。
- 右クリックでコンテキストメニューを表示し、「採用にする」「没にする」「未分類に戻す」を実行できます。
- 未選択のセル上で右クリックした場合は、先にそのセルを選択してからメニューが表示されます。
- 複数選択に対応：
  - ⌘クリックで個別に追加/解除
  - ⇧クリックで同一ペイン内を範囲選択

**キーボードで操作:**
- 矢印キーで（アクティブなペイン内の）選択を移動
- ⌥（Option）+↑/↓ でフォルダツリーの選択を移動、⌥（Option）+→/← でフォルダの展開/折りたたみ
- ⌘1 で選択を採択に、⌘2 でボツに、⌘0 で未分類に戻す
- ⌘A でアクティブなペインを全選択、⌘D で選択解除
- スペースキーまたはEnterキーで選択中の写真の拡大プレビューを開く（もう一度押すと閉じる）

### 3. ボツ写真を移動する

1. 右上の「Move Discarded (没)」ボタンをクリック
2. 移動先は「現在のフォルダと同じ階層にある『<現在のフォルダ名>_没』フォルダ」です。
   - サンドボックス等の理由で作成できない場合は、フォールバックとして「現在のフォルダ/没」を使用します。
3. 移動した写真はリアルタイムで一覧から削除されます

## 画面の構成

メインウィンドウは 3 ペイン構成です：

- 左：フォルダツリー（選択したフォルダを読み込み）
- 中央：写真グリッド（現在フォルダの写真一覧）
- 右：プレビュー（上）と 採用/没 リスト（下、左右分割）

補足：
- 現在アクティブなペインが淡くハイライトされ、キーボード操作や ⌘A はそのペインに対して実行されます。
- 中央・採用・没 の各グリッドは、選択が画面外になった場合に自動スクロールします。

### フォルダツリー

フォルダツリー内のフォルダを右クリックするとコンテキストメニューが表示されます：

- **Finderで開く**: そのフォルダをFinderで表示します。
- **新規フォルダ**: 名前を入力して、そのフォルダ内に新しいサブフォルダを作成します。
- **フォルダ名を変更**: フォルダ名を変更します。開いているルートフォルダに対しては無効です。
- **フォルダを削除**: 確認ダイアログの後、フォルダをゴミ箱に移動します。ルートフォルダに対しては無効です。

ドラッグ＆ドロップ：

- グリッドや採用/没リストから写真をドラッグし、フォルダツリー内のフォルダ、または写真グリッド自体にドロップすると、そのフォルダへ移動します。
- ドロップ時に ⌥（Option）キーを押しておくと、移動ではなくコピーになります。
- ドラッグ元またはドロップ先が外部/リムーバブルドライブの場合は、自動的に移動ではなくコピーになります。
- ルートフォルダを除き、フォルダ自体もドラッグ可能です。サブフォルダを別のフォルダにドラッグして整理できます。
- 移動/コピー先に同名の項目がすでにある場合は、「**両方とも残す**」「**置き換える**」「**中止**」を選ぶダイアログが表示されます（「以降の競合にも同じ処理を適用」のチェックボックスあり）。
- このようにして行った移動・コピーは ⌘Z で取り消し（⇧⌘Zでやり直し）できます。

### ツールバー / メニュー

- **Open Folder**: フォルダを開く
- **サムネイルサイズスライダー**: 写真の表示サイズを変更（100〜400px）
- **日付ソート**: 「File（既定・高速）」か「EXIF（撮影日時・低速）」を選択できます。プレビューの日時表示もこの設定に従います。
- **Clear**: すべての分類をリセット
- **写真数表示**: 現在読み込んでいる写真の枚数
- **Move Discarded**: ボツ写真を移動（移動先ポリシーは上記参照）
- メニューバーの「仕分け」からも同じ操作（採用⌘1／没⌘2／未分類⌘0・全選択⌘A・選択解除⌘D）が可能。操作対象はアクティブなペインです。

## キーボード操作

### 選択と移動（アクティブなペイン）

| キー | 動作 |
|------|------|
| ↑ / ↓ / ← / → | 選択を移動 |
| ⌥（Option）+ ↑ / ↓ | フォルダツリーの選択を移動 |
| ⌥（Option）+ → / ← | フォルダを展開／折りたたみ |
| ⌘A | そのペインの全選択 |
| ⌘D | 選択解除 |

### 写真の操作

| キー | 動作 |
|------|------|
| ⌘1 | 選択を採択にする |
| ⌘2 | 選択をボツにする |
| ⌘0 | 選択を未分類に戻す |
| スペース / Enter | 選択中の写真の拡大プレビューを開く（もう一度押すと閉じる） |

補足: クリックだけでは状態は切り替わりません。⌘1／⌘2／⌘0、右クリックのコンテキストメニュー、または「仕分け」メニューを使用してください。

### 拡大表示中の操作

| キー | 動作 |
|------|------|
| スペース / Enter | 拡大表示を閉じる |
| ⌘W | 拡大表示を閉じる |
| ダブルクリック | 「ウィンドウに合わせる」表示と等倍（100%）表示を切り替え |
| ピンチ操作 | 拡大・縮小 |
| ドラッグ、または2本指スクロール | 拡大時に画像を移動（パン） |

## 写真の分類方法

### おすすめのワークフロー

1. **フォルダを開く**
   - 整理したい写真フォルダを選択

2. **ざっと見て分類**
   - 矢印キーで次々と写真を確認
   - ⌘1／⌘2（または右クリックメニュー、「仕分け」メニュー）で瞬時に採択/ボツを判断
   - 迷ったら未分類のまま飛ばす

3. **プレビューで確認**
   - 右側のプレビューで大きく確認
   - スペースキーまたはEnterキーでさらに大きく（拡大表示）可能

4. **最終確認**
   - 右下のボツリストで移動する写真を確認

5. **移動実行**
   - 「Move Discarded (没)」ボタンで移動

6. **未分類を再確認**
   - 残った未分類の写真を再度確認

## RAWファイル対応

標準的な画像形式に加えて、photoSelectorは主要なカメラRAW形式を直接読み込めます（macOS標準のImageIO RAWデコード機能を利用するため、事前の変換は不要です）：

- Canon: CR2, CR3
- Nikon: NEF, NRW
- Sony: ARW
- Fujifilm: RAF
- OM System / Olympus: ORF
- Panasonic: RW2
- Pentax: PEF
- Adobe / Leica ほか: DNG

RAWファイルにはサムネイル上に小さな「RAW」バッジが表示され、同じカットのJPEGと一目で区別できます。

サムネイルのデコードに失敗した場合（ファイル破損、非対応のRAWバリエーション、読み取り不能なメディアなど）は、読み込み中のまま止まる代わりに警告アイコンが表示されます。

## レイアウトのカスタマイズ

### 分割線の調整

アプリ内の3つの境界線はすべてドラッグして調整できます：

1. **左右の分割線**
   - 写真一覧とプレビュー/ボツリストの幅を調整

2. **上下の分割線（右側）**
   - プレビューとボツリストの高さを調整

3. **サムネイルサイズ**
   - スライダーで写真のサイズを変更

### 拡大表示ウィンドウ

- ウィンドウの角をドラッグしてサイズ変更可能
- 画像は自動的にウィンドウサイズに合わせて表示されます

## 設定の保存

アプリの実行中は、各ウィンドウが自身の分割位置やウィンドウサイズを調整のたびに記憶しています。ただし、これだけでは**次回起動時には引き継がれません**。起動するたびに新しいウィンドウとして開始します。

現在のレイアウトを次回以降の起動でも使えるようにする（＝新しく開くウィンドウにも適用する）には、メニューバーの **「ウィンドウ」→「現在の設定とレイアウトをデフォルトにする」** を実行してください。この操作で以下が保存されます：

- すべての分割位置（メイン左右、右側上下、採用/没の境界）
- サムネイルサイズ（スライダーの位置）
- 日付ソートモード（File / EXIF）
- サイドバーのEXIFペインの高さ
- メインウィンドウのサイズ

保存されたレイアウトは、次に開くすべての新しいウィンドウ（次回アプリ起動時のウィンドウを含む）に自動的に適用されます。現在の配置を新たにデフォルトにしたい場合は、このコマンドをもう一度実行してください。

なお、ライト/ダークモード（メニューバーから設定）はこの操作とは別に、常に自動的に記憶されます。

拡大表示ウィンドウのサイズと位置についても、上記とは独立に自動的に保存され、次に開いたときに復元されます。

## 並び順（ソート）

- 既定: ファイル作成日時（高速。ファイルシステムのメタデータのみを使用）
- オプション: EXIF日時（低速。画像メタデータを読み出し、無い場合はファイル日時にフォールバック）
- ツールバーの「Date」セグメント（File / EXIF）で切り替え。切替後すぐに反映されます。

## Tips

### 効率的な分類のコツ

1. **キーボード操作を活用**
   - マウスを使わず、矢印キーと⌘1／⌘2／⌘0だけで高速に分類できます

2. **自動スクロール**
   - 矢印キーで選択を移動すると、自動的にスクロールして選択中の写真が見えるようにします

3. **サムネイルサイズの調整**
   - 細かく確認したいときは大きく
   - 大量の写真を一度に見たいときは小さく

4. **プレビューの活用**
   - 右側のプレビューで常に選択中の写真を確認できます
   - スペースキーまたはEnterキーで拡大表示を開く/閉じる（トグル動作）

5. **段階的な分類**
   - 1回目: 明らかなボツだけを分類
   - 2回目: 採択を選ぶ
   - 3回目: 残った未分類を最終判断

## トラブルシューティング

### 写真が表示されない

- 対応している画像形式か確認してください（JPG, PNG, HEIC, GIF, TIFF、および[対応RAW形式](#rawファイル対応)）
- フォルダの読み取り権限を確認してください
- サムネイルに警告アイコンが表示される場合、そのファイルのデコードに失敗しています（破損しているか、非対応のRAWバリエーションの可能性があります）

### キーボードが反応しない

- 写真一覧エリアをクリックしてフォーカスを当ててください

### アプリが複数起動してしまう

- このアプリは単一インスタンス設計です
- 既に起動している場合、2回目の起動は既存のウィンドウをアクティブにします

## システム要件

- macOS 26.1以降
- 対応画像形式: JPG, JPEG, PNG, HEIC, GIF, TIFF、および[RAWファイル対応](#rawファイル対応)に記載のRAW形式

## プライバシーとセキュリティ

- このアプリは選択したフォルダにのみアクセスします
- ネットワーク接続は一切行いません
- 写真データは外部に送信されません
- すべての処理はローカルで完結します
